## 4-Tier Pedagogical Progression Framework

Our syllabus is divided into 4 strategic proficiency tiers tailored to your target score:

| Band Stage | Target Audience | Pedagogical Focus |
| :--- | :--- | :--- |
| **Stage 1: Foundation & Survival** | **Band 4.0 – 5.0** (Beginner / Core rebuild) | Syntactic clarity, 4-paragraph Task 2 templates, securing high marks in Section 1 Listening and Passage 1 Reading. |
| **Stage 2: Question Type Mastery** | **Band 5.5 – 6.5** (Intermediate test-takers) | Comprehensive mastery of all Task 1 visual formats, Task 2 prompt types, True/False/Not Given, and Matching Headings. |
| **Stage 3: High-Band Breakthrough** | **Band 7.0 – 8.5+** (Advanced aspirants) | Academic hedging, thematic progression, macro-to-micro Part 3 argumentation, C1/C2 collocations, and counter-argument refutations. |
| **Stage 4: Exam Simulation & CDI Tactics** | **All Computer-Delivered Test-Takers** | Keyboard speed, split-screen note-taking, text-highlighting shortcuts, and One Skill Retake (OSR) tactics. |
