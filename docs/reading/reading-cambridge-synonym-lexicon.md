### Ma Trận Từ Đồng Nghĩa Cambridge IELTS
Các giám khảo Cambridge khi thiết kế câu hỏi luôn tuân thủ nguyên tắc hoán đổi từ vựng theo bảng tương đương:

| Từ Khóa Trong Câu Hỏi (Question Stem) | Từ Thực Tế Xuất Hiện Trong Bài Đọc (Passage Text) |
|---|---|
| **solve / tackle a problem** | address / overcome / mitigate a dilemma / crisis |
| **significant / dramatic decrease** | precipitous plunge / sharp downturn / substantial drop |
| **rely heavily on** | be excessively dependent upon / place reliance on |
| **financial assistance / funding** | state subsidy / grant / monetary sponsorship |
| **harmful / detrimental impact** | adverse repercussions / pernicious consequences |
| **traditional methods** | conventional practices / orthodox techniques |
| **disclose / reveal information** | divulge / unveil / make public |
| **annual / every year** | per annum / yearly occurrence |
| **skeptical / doubtful about** | express reservations / dispute the validity of |
| **imitate / copy** | emulate / replicate / mirror |
| **limit / restrict** | constrain / curtail / impede |
| **unexpected finding** | counter-intuitive discovery / surprising revelation |
| **resemble / look like** | bear striking similarities to / share morphological traits |
| **artificial / man-made** | synthetic / manufactured / engineered |
| **dangerous / risky** | perilous / hazardous / precarious |
| **flourish / thrive** | burgeon / proliferate / boom |
| **initial / early stage** | embryonic phase / nascent period / inception |
| **mandatory / compulsory** | obligatory / legally required / statutory |
| **scarce / rare** | deficient / sparsely distributed / meagre |
| **primary cause** | root catalyst / chief determinant / prime driving factor |
